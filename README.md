# 🚀 Personal Portfolio Website

A modern, premium portfolio website with stunning animations, glassmorphism design, and dark theme.

![Portfolio Preview](preview.png)

## ✨ Features

- 🎨 Glassmorphism UI with animated gradient backgrounds
- 🌙 Dark mode with vibrant accent colors
- 📱 Fully responsive (mobile + desktop)
- ⚡ Smooth scroll animations & micro-interactions
- 🎯 Custom cursor effects
- 📊 Animated counters & skill bars
- 💼 Experience timeline
- 🖼️ Project showcase with hover effects
- 📬 Contact form

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts
